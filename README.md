## 🚀 Deployment Instructions for GitHub Pages

1. **Initialize Git & Add Remote**:
   ```bash
   git init
   git remote add origin https://github.com/vnishant41/vnishant41.github.io.git
   ```

2. **Commit & Push**:
   ```bash
   git add .
   git commit -m "Deploy interactive portfolio with IPGA data management & Advanced MIS system"
   git branch -M main
   git push -u origin main --force
   ```

3. **Enable GitHub Pages**:
   - Go to `https://github.com/vnishant41/vnishant41.github.io/settings/pages`
   - Select **Source: Deploy from a branch**
   - Branch: `main` / Folder: `/(root)`
   - Click **Save**.
