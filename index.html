PROJECT 01 · DATA ENGINEERING & AUTOMATION

IPGA Daily Price CSV Conversion Workflow

Excel / VBA / Data Engineering

Engineered an automated data management workflow for daily market price feeds from the India Pulses and Grains Association (IPGA). Built as a proactive organizational solution, the system normalizes heterogeneous input feeds into clean, validated CSV datasets ready for database ingestion and research reporting.

The Problem

Raw IPGA feeds contained inconsistent regional mandi spellings (e.g. Gulbarga vs Kalaburagi), mixed trade units (Rs/20kg, 50kg bags, trucks, $/MT), and non-standard variety names.

The Solution

Built an entity mapping matrix and VBA macro validation engine that automatically converts unit weights to standard quintals/tonnes and standardizes location/variety names.

The Outcome

Reduced daily report preparation time, eliminated entity duplication errors, and output standardized CSV tables for Spot Rates, Arrivals, and C&F Prices.
